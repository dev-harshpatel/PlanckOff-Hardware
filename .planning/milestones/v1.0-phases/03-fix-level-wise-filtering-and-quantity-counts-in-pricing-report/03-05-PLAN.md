  <what-built>
    Plans 01-04 fixed four distinct bugs in the Pricing Report level-wise filtering pipeline:
    - Plan 01: client-side Excel parser now recognizes 'BUILDINGN AREA' / 'BUILDING AREA' as buildingLocation
    - Plan 02: server/DB transformer now falls back to row.buildingArea when row.buildingLocation is missing
    - Plan 03: pricing export now receives filtered visibleDoors/visibleFrames (not raw doorGroups/frameGroups)
    - Plan 04: door and frame count badges now sum g.totalQty (not g.doors.length)

    Combined effect: For Mixed Use Kamloops the Building Location filter dropdown now shows LEVEL 01 / LEVEL 02 options, selecting one filters the table correctly, count badges show sum-of-quantities, exports match the filtered UI, and the detail modal stays consistent because it reads from visibleDoors/visibleFrames/visibleHardware.
