<objective>
Close the three Realtime / pricing-page error surfaces that currently swallow failures:

1. Add a new `REALTIME_ERRORS` registry object (in a new domain file `constants/errors/realtime.ts`) with a `SUBSCRIPTION_FAILED` entry; re-export it via `constants/errors/index.ts` and add it to the `ERRORS` namespace.

4. In `app/project/[id]/reports/pricing/page.tsx`, replace the `noopToast` with the real `addToast` from `useToast()`, so subscription errors actually surface on the pricing page (per ROADMAP success criterion #5).

Purpose: ERR-03 — every known failure point maps to a registry entry. ERR-06 — all error surfaces (toasts, modals, banners) use the registry exclusively. Today the Realtime subscription failure has no registry entry and no user-visible surface; the pricing page additionally silences ALL toasts including subscription-error toasts via `noopToast`.

Output: One new registry file, one updated index, two updated hooks, one updated page. Subscription errors now produce a user-visible toast on every project page including the pricing page.
